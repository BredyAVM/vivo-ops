# VIVO Admin: instalación y notificaciones

## Uso

- Abrir Administración → App y notificaciones (`/app/admin/notificaciones`).
- Android: instalar desde el botón disponible o desde el menú de Chrome.
- iPhone/iPad: Safari → Compartir → Añadir a pantalla de inicio. Requiere iOS/iPadOS 16.4+ para Web Push; abrir desde el icono instalado.
- Dentro de la app, pulsar **Activar notificaciones** y aceptar el permiso del teléfono. **Enviar prueba** envía solo al dispositivo seleccionado por esa sesión.
- La app requiere conexión para órdenes, cuentas y operaciones financieras. No es una aplicación financiera offline ni un APK.

## Arquitectura y seguridad

- Identidad propia `/app/admin`; manifest estático `/pwa/admin.webmanifest`, público y sin datos del negocio. No depende de cookies ni de convenciones de metadata anidadas de Next.js.
- Worker dedicado `/admin-sw.js`, alcance `/app/admin`, reutiliza `/vivo-sw.js`. No reemplaza la suscripción de Asesor ni la del Master.
- Registrar el worker no pide permisos ni crea suscripciones. Si ya existe una, se vincula de nuevo únicamente a la sesión administrativa verificada.
- El servidor verifica la sesión y el rol `admin` al registrar. La entrega a suscripciones administrativas vuelve a verificar ese rol. Las rutas de avisos permanecen dentro de Administración.
- Cerrar sesión desde Administración desactiva la suscripción local de ese dispositivo. Las suscripciones de otros roles permanecen intactas.
- Solo se cachean recursos estáticos; no se guardan respuestas HTML, consultas API, saldos ni operaciones. No se agregan consultas periódicas financieras.
- Se usan las tablas, claves VAPID y avisos por rol existentes. No requiere migración de base de datos. No agrega tipos nuevos de alerta: conecta los que ya publica el sistema para administradores.

## Verificación

- `npm run test:admin-pwa`: identidad, iconos, separación de roles/workers, rutas de avisos, permisos del servidor, logout y caché sin datos financieros.
- Compilación de producción y suite administrativa/seguridad antes de publicar.
- Después de publicar: comprobar pantalla e instalación; el permiso del teléfono y la recepción de la notificación deben verificarse en un dispositivo real, con intervención del administrador. No se envían avisos reales durante pruebas automáticas.
